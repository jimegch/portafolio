Proyecto académico · Desarrollo web

DemocraXSSy

Descripción del proyecto

Juego de cartas multijugador desarrollado como aplicación web, inspirado en la sátira política y el humor. Permite crear partidas, incorporar jugadores y participar en diferentes rondas hasta finalizar el juego.

La aplicación cuenta con una interfaz que permite conectarse a diferentes servidores y comunicarse con un backend mediante APIs, utilizando conexiones HTTP o HTTPS.

Herramientas y tecnologías

React JavaScript OCI

Mi participación

  • Desarrollo de componentes de la interfaz utilizando React.
  • Implementación de funcionalidades para las distintas fases del juego.
  • Integración de la interfaz con las APIs del servidor.
  • Implementación de validaciones y manejo de respuestas del backend.
  • Participación en el desarrollo de la lógica del servidor.

Aprendizajes

Fortalecí mis conocimientos sobre la comunicación entre frontend y backend, el consumo de APIs, la validación de datos y la organización de componentes en React. También adquirí experiencia resolviendo problemas de integración y funcionamiento de aplicaciones multijugador.
